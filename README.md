# 📚 Joseettan's Vayanashala (Joseettan's Reading Room)

> **Grade 12 Computer Science Project**

Welcome to **Joseettan's Vayanashala**! This repository contains the source code and documentation for a Library / Reading Room Management System developed as part of the Class 12 Computer Science curriculum.

---

## 🌟 Overview

Inspired by the warmth and tradition of local reading rooms, *Joseettan's Vayanashala* provides a simple, structured system to manage book collections, member records, and borrowing activity seamlessly.

The main goal of this project is to apply core computer science concepts learned in Class 12—such as relational databases, SQL integration, and structured programming in Python—to solve a real-world utility problem.

---

## ✨ Features

* 📖 **Book Management:** Add, update, view, and search available books in the library.
* 👤 **Member Registration:** Track readers, issue new membership records, and update profile details.
* 🔄 **Issue & Return System:** Process book borrowing and returns with date tracking.
* 🔍 **Search & Query:** Quickly look up books by title, author, or availability.
* 📊 **Persistent Storage:** MySQL database integration for managing books and member records.

---

## 🛠️ Built With

* **Language:** Python 3.x
* **Database:** MySQL
* **Interface:** Command Line Interface (CLI)
